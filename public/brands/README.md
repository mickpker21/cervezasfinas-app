Reglas de nombrado:
- El nombre mostrado en Admin/NuevaEvaluación se convierte a “slug”: minúsculas, sin acentos, espacios y símbolos a guiones.
- Ejemplo: "Dos Equis Lager" -> "dos-equis-lager.png".

Notas:
- Si una imagen no existe, la tarjeta mostrará solo el texto de la marca.
- Puedes añadir más marcas; solo agrega el archivo PNG correspondiente y pon el nombre en la configuración.
